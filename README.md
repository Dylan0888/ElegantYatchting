# Elegant Yachting Website 
A modern luxury yacht charter website built with React, TypeScript, and Tailwind CSS. Elegant Yachting showcases premium yacht experiences through immersive visuals, responsive layouts, and an elegant user interface inspired by high-end travel and hospitality brands.

The project focuses on creating a polished, component-driven frontend while demonstrating modern React development practices.

## Live Preview 



## Features 
- Modern luxury-inspired responsive design
- Interactive gallery with dynamic filtering
- Individual tour experience pages using React Router
- Reusable component architecture
- Responsive navigation
- Hero sections with cinematic layouts
- Dynamic gallery generated from JSON data
- Tour cards with hover animations
- Clean and scalable project structure
- Mobile-first design
- Smooth transitions and animations
- Type-safe development with TypeScript

## Learning Objective
This project was created to strengthen my frontend development skills while building a realistic luxury travel website.

Key learning goals include:

- Building scalable React applications
- Creating reusable UI components
- Working with TypeScript interfaces and props
- Managing application state with React Hooks
- Implementing dynamic routing with React Router
- Building responsive layouts using Tailwind CSS
- Organising larger React projects into reusable components
- Working with JSON-driven content
- Creating interactive filtering functionality
- Improving UI/UX design principles
